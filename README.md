# EcoShoppr

Welcome to **EcoShoppr** - Your local grocery price optimization platform.

## Vision

The goal of this application is to scrape data from local supermarkets, grocery stores, cafes, and restaurants, and aggregate all of that information into a single, scalable web app. Anyone can use the platform to view and find the cheapest items available locally, starting with a focus on the Santa Cruz area to test scalability and viability.

By compiling an online record of grocery store prices, EcoShoppr empowers the consumer to compare prices of individual items across different stores, allowing them to shop in a more economical and "eco" friendly manner. Additionally, we aim to work with small businesses to help them create an online presence and showcase their products and prices to the community.

## Architecture

* **Frontend**: Built with React, TypeScript, and Vite for a fast, responsive, and visually appealing user experience. 
* **Backend/Scrapers** (To be developed): Future work will involve constructing resilient and automated scrapers tailored for the Santa Cruz region's markets.

## Getting Started

To run the local development server for the webapp:

```bash
cd webapp
npm install
npm run dev
```
